# II RP 1939 Poland GeoJSON

This repository contains historical GeoJSON geometry files for comparison and GIS prototyping related to the borders of the Second Polish Republic (II Rzeczpospolita, 1939).

Important note:
- These files are historical reconstructions for comparison, not official legal boundary datasets.
- The country outline is aligned to the public historical world boundary dataset from `historical-basemaps` (`world_1938.geojson`), which is a public historical country outline layer.
- The voivodeship layer is reconstructed for historical comparison and is marked as an approximation.
- All coordinates are in WGS84 / EPSG:4326.

Files:
- `poland_1939_outline_full.geojson` — full country outline (approximate polygon)
- `poland_1939_outline_simplified.geojson` — simplified country outline
- `poland_1939_voivodeships_full.geojson` — reconstructed voivodeship layer for 1939
- `poland_1939_voivodeships_simplified.geojson` — simplified voivodeship layer

Sources used:
- `historical-basemaps` / `geojson/world_1938.geojson` — historical country outline reference
- Historical atlas and public historical cartographic references for the II RP administrative division

## Notes

A direct, public, fully official GeoJSON of the 1939 Polish `województwa` layer is not widely available as a ready-made single-source dataset. The files here are therefore designed as a practical working approximation for map prototyping, comparison, and historical visualization.
